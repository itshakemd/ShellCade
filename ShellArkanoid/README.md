# Shell Arkanoid

Break the colored brick wall with a paddle and bouncing ball in the terminal.

## Run

From the repository root:

```text
python -m ShellArkanoid.main
```

Windows users can double-click `arkanoid.bat`.

## Controls

- `A` / `D` or the arrow keys: move the paddle
- `P`: pause and resume
- `R`: restart after a round ends
- `Q`: quit

## Tests

```text
python -m unittest ShellArkanoid.test_game
```
