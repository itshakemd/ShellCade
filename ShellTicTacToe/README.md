# Shell Tic-Tac-Toe

Play Tic-Tac-Toe in the terminal against a simple computer opponent or
another person at the same keyboard.

## Run

```text
python -m ShellTicTacToe
```

Windows users can double-click `tictactoe.bat`.

## Controls

Choose a mode from the menu with `W/S` or Up/Down and Enter. During a match,
select board positions with keys `1` through `9`. Press `R` to restart and
`Q` to return to the menu.

## Tests

```text
python -m unittest ShellTicTacToe.test_game
```
