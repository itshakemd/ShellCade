# ShellFlappyBird

ShellFlappyBird is a Blessed-powered terminal Flappy Bird game.

## Run

Install dependencies from the repository root, then run `python main.py` or
launch `flappy.bat`.

## Controls

- `Space` / `Enter` flap
- `P` pause or resume
- `R` restart after a crash
- `Q` return to the menu

Run the tests with `python -m unittest test_game.py`.
