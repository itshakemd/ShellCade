# ShellPong

ShellPong is a Windows terminal Pong game with single-player and two-player
modes.

## Run

From this directory:

```text
python main.py
```

You can also launch `pong.bat`.

## Controls

- Single player: `W` / `S` move Player 1; the computer controls Player 2.
- Two players: `W` / `S` control Player 1; Up / Down control Player 2.
- `P` pauses and `Q` quits.

The first player to reach seven points wins.
